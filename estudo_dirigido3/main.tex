\section*{Questão 1 - Qual comando principal para iniciar o treinamento de um modelo?}
O método principal para iniciar o treinamento de um modelo usando Scikit-learn é o método \texttt{fit()}

\section*{Questão 2 - Qual comando utilizado para classificação das amostras?}
Após o treinamento do modelo, o comando utilizado para realizar a classificação das amostras é o método \texttt{predict()}.

\section*{Questão 3 - Para que servem os pipelines?}
Serve para encadear as várias etapas necessárias para treinar um modelo em um único objeto unificado.

\section*{Questão 4 -  Como podemos usar uma árvore de decisão para realizar uma predição numérica?}
Para problemas de regressão númerica, toda a estrutura básica da árvore de decisão é mantida (nó raiz, nós internos e folhas), entretando, ao invés de utilizar métricas que levam em consideração pureza ou ganho de informação como Índice de Gini e Entropia para dividir os dados, é utilizado o Erro Quadrático Médio (MSE) para encontrar as subdivisões que resultam no menor MSE.

\section*{Questão 5 - O que são as fronteiras de decisão?}
É a região que separa as diferentes classes em um espaço de características, como uma linha que separa duas classes em espaço cartesiano. As fronteira de decisão permitem visualizar quais áreas do espaço de características são classificadas como pertencentes a cada classe, e como o modelo está tomando suas decisões de classificação.

\section*{Questão 6 - Qual comando utilizado para particionamento de dados entre treino e teste? Quais seus
principais argumentos?}
\texttt{train\_test\_split()} é o comando utilizado para particionar os dados entre treino e teste. Seus principais argumentos são: *arrays: o dataset a ser dividido; test\_size: a proporção do dataset a ser alocado para o conjunto de teste; train\_size: a proporção do dataset a ser alocada para o conjunto de treino; random\_state: um número inteiro que controla a embaralhamento antes da divisão dos dados; shuffle: um booleano que indica se os dados devem ser embaralhados antes da divisão; stratify: um array que é usado para garantir que a divisão dos dados seja estratificada, ou seja, que a proporção de classes seja mantida em ambos os conjuntos de treino e teste.
